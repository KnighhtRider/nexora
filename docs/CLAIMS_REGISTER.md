# Claims Register

Every factual statement on the site must map to an entry. Agents check this before writing any copy. Status: **ALLOWED**, **NEEDS PROOF** (do not publish), **FORBIDDEN**.

## Forbidden until independently proven (and approved by the human)
SOC 2 · ISO 27001 · GDPR-compliant / "fully compliant" · HIPAA · PCI · "99.9% uptime" or any uptime figure · "trusted by …" · customer logos · testimonials · case studies · ROI/time-saved/percent-improvement metrics · "used by Fortune 500" · "bank-level / military-grade security" · "unbreakable" · awards · headcount · office locations · founders/team (unless supplied by the human) · "production-ready" / "available now" for any module · "real-time" (unless true) · named third-party integrations as supported (design approach only).

## Wording patterns
Prefer "designed to", "intended to", "proposed", "concept". Avoid "guarantees", "ensures", "eliminates", "always".
