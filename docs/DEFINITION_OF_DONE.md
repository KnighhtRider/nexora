# Definition of Done (every task)

- [ ] Acceptance criteria met and demonstrated.
- [ ] `npm run verify` is green (format, lint, typecheck, unit tests, build) and the output was actually observed.
- [ ] UI tasks: screenshots at 375 and 1440 match the target; no horizontal scroll at 320.
- [ ] Keyboard: every control reachable, visible focus ring, logical order.
- [ ] Reduced-motion and no-WebGL paths checked where relevant.
- [ ] No console errors or hydration warnings.
- [ ] No new dependency without approval; `docs/STACK_LOCK.md` updated if one was approved.
- [ ] No placeholder text, dead links or invented claims; `docs/CLAIMS_REGISTER.md` respected.
- [ ] `docs/SESSION_HANDOFF.md` updated; any decision logged in `docs/DECISIONS.md`.
- [ ] Report lists: changed files, commands run, real results, remaining issues.
