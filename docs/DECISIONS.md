| 2026-11-19 | **[fixed]** `line-strong` = `#5C6E8C`, not `#4A5B78` | `#4A5B78` measured 2.87:1 on `page`, 2.61 on `surface`, 2.32 on `elevated` — it failed WCAG 1.4.11 on every surface while the spec required it for form borders. |
| 2026-11-19 | **[fixed]** `--duration-*` get explicit `@utility` declarations; Tailwind's `--ease-in-out` is never redefined (use `--ease-smooth`) | Tailwind v4 has no `--duration-*` namespace, so `duration-fast` silently did not exist; redefining `--ease-in-out` silently restyles every transition in the project. |
| 2026-11-19 | **[fixed]** Type scale is declared as `--text-*` tokens | Clamp values in prose made `text-[clamp(...)]` the only implementable option, which the "no arbitrary values" rule forbids. |
| 2026-11-19 | **[accepted]** Preview-only routes (`/design-system`, `/lab/ai-core`) gate on `VERCEL_ENV !== 'production'` (or an explicit `PREVIEW_TOOLS` flag), never on `NODE_ENV` | Vercel preview deployments build with `NODE_ENV=production`; the old rule 404'd the gallery on the very preview the human has to approve. |
| 2026-11-19 | **[accepted]** Form transport = Route Handlers (`POST /api/request-demo`, `POST /api/contact`) | Already assumed by TESTING and the phase docs; Server Actions would invalidate the 400/413/429/503 handler tests and change the CSP/JS story. One choice, not two. |
| 2026-11-19 | **[accepted]** Rate limiting via hosting-layer rules (Vercel WAF), no key-value store | Keeps "no database" in STACK_LOCK true and adds no dependency or secret. Revisit only if platform rules prove insufficient. |
| 2026-11-19 | **[accepted]** MDX = `@next/mdx` (build-time compile), decided in Phase 2 | `next-mdx-remote` fetches at runtime; the two imply different Resources index and tag-filter designs. |
| 2026-11-19 | **[accepted]** Demo steps are visitor-driven (`ADVANCE`); auto-play is opt-in and off by default | Removes focus stealing, removes WCAG 2.2.x exposure, and removes every `waitForTimeout` from E2E. |
| 2026-11-19 | **[accepted]** Root `README.md` becomes the project README; the pack index lives at `docs/README.md` only | The two files were byte-identical; duplicate indexes drift. |
| 2026-11-19 | **[accepted]** CSP stays report-only until T8.3; a nonce via `proxy.ts` is adopted only if dynamic rendering is acceptable | A nonce forces dynamic rendering on every route, which gives up static generation for the whole marketing site. |
| 2026-11-19 | **[accepted]** `docs/ARCHITECTURE.md` defines the `src/` tree and import direction as a review rule: `features/` never imports `app/` or another feature; `content/`, `config/` and `lib/` import nothing upward | Boundaries lived only in prose, so nothing could catch a violation. |
| 2026-11-19 | **[accepted]** Oversized task cards are pre-split in their phase file ("Split before use") | An agent that hits the size cap mid-task either stops halfway or ignores the cap and sets a precedent. |
| 2026-11-19 | **[accepted]** Initial-JS budget revised from ≤130 KB gz to ≤240 KB gz (≤210 KB br) for `/` excluding the 3D chunk; final number fixed at the Phase 3 gate | Measured floor with zero app code is 170.4 gz / 146.9 br (Next 16.4.6 + React 19.3.0, `STACK_LOCK.md`). The original figure was unachievable and would have produced a doomed Phase 4. |
| 2026-11-19 | **[accepted]** Budgets are stated in both gzip and Brotli, and measured by parsing the prerendered page's script tags | Vercel serves Brotli; Next 16 no longer prints "First Load JS" in the build output, so the number has to be derived from the built HTML or it is never measured at all. |
| 2026-11-19 | **[accepted]** `@types/node` raised from `^20` to `^26` in T0.3 | Vitest 5.1.1 requires `@types/node ^22 \|\| >=24` and the runtime is Node 26.13.0. Holding the stale types would have meant `--legacy-peer-deps` on every install. |
| 2026-11-19 | **[accepted]** Playwright never reuses an existing server on port 3100 (`reuseExistingServer: false`) | A leftover server makes a run pass against an older build. T0.3 hit exactly that: an axe contrast fix appeared to fail twice because the browser was served the previous CSS. A wrong green is worse than a slow run. |
| 2026-11-19 | **[accepted]** The scaffold `globals.css` is dark-only (`html { color-scheme: dark }`) until T1.1 replaces the block with the design tokens | The page set `text-neutral-50` while the background still flipped to white for light-mode visitors, so the H1 and label failed WCAG contrast (caught by axe, serious). DESIGN_SYSTEM already specifies `color-scheme: dark`. |
| 2026-11-19 | **[accepted]** `verify:full` = `verify` + `test:e2e` + `test:visual`; it does not re-run `test:a11y` | Every a11y test is `@a11y`-tagged inside the e2e suite, which already runs it. A separate pass would rebuild the app and start a second server to execute the same assertion. `test:a11y` remains for local iteration. |
| 2026-11-19 | **[accepted]** Lighthouse CI ships as `.lighthouserc.json` only; no CI job until `@lhci/cli` is approved | The card allows a stub, and a job using `npx @lhci/cli` would add an unapproved dependency and paint CI red on day one. Budgets are already in the stub as `warn`, so wiring it later is a one-line job. |
